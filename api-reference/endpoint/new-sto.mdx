---
title: 'New STO'
openapi: 'POST /prepare-transactions'
---

This endpoint prepares transactions for creating a new Security Token Offering (STO).

## Method

Use the `newSto` method in your request to prepare STO creation transactions.

```json
{
  "method": "newSto",
  "signerAddress": "0x...",
  "chainId": "0x1",
  // Additional STO parameters
}
```
