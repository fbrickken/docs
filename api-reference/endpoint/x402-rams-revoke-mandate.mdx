---
title: 'Revoke RAMS Mandate'
openapi: 'POST /x402/rams/revoke-mandate'
description: 'Prepare revocation of an ERC-8226 mandate.'
---

Maps to `ramsRevokeMandate` for an `agent` / `principal` pair.

## Authorization modes

| Mode | Authorization |
| --- | --- |
| Direct | `signerAddress` is the principal or an approved operator |
| Principal signature | Any sender supplies `signature` and the matching `deadline` from [Typed Data](/api-reference/endpoint/rams-typed-data) |
| Brickken relayed | Principal signature plus `executionMode: "brickken-relayed"` |

The API preflights that the mandate is active. The response contains the unsigned transaction and `info.mode`; pay x402 only when sending.
