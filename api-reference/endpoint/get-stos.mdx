---
title: 'Get STOs'
openapi: 'GET /get-stos'
---

Lists every Security Token Offering of a tokenized asset. The response is a JSON array, not an object.

## Query Parameters

- `tokenSymbol` (required): Token symbol

## Example

```bash
curl --request GET \
  --url 'https://api.sandbox.brickken.com/get-stos?tokenSymbol=EXMPL' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

    "uuid": "a5232594-3f97-47d0-b362-491caac9388f",
    "name": "Round A",
    "status": "active",
    "tokenAmount": "100000",
    "hardCap": "500000",
    "softCap": "50000",
    "maxInvestment": "10000",
    "minInvestment": "100",
    "tokenSymbol": "EXMPL",
    "startDate": "2026-01-01T00:00:00.000Z",
    "endDate": "2026-12-31T23:59:59.000Z",

    "acceptedCoin": "USDC",

Use `uuid` as the `id` parameter of [`GET /get-sto-by-id`](/api-reference/endpoint/get-sto-by-id),
[`GET /get-sto-balance`](/api-reference/endpoint/get-sto-balance), and
