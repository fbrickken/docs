---
title: 'Close Offer'
openapi: 'POST /prepare-transactions'
---

This endpoint prepares transactions for closing an STO offer.

## Method

Use the `closeOffer` method in your request to prepare offer closing transactions.

```json
{
  "method": "closeOffer",
  "signerAddress": "0x...",
  "chainId": "0x1",
  // Additional closing parameters
}
```
