Prepares unsigned transactions for approving an agent-owned ERC-20 token allowance. This facade maps to `agentApproveToken`.

## Key Fields

| Parameter | Required | Description |
| --- | --- | --- |
| `chainId` | Yes | Target chain ID. Use `8453` for Base mainnet or `84532` for Base Sepolia. Decimal and hex values are accepted. |
| `executionMode` | No | `brickken-relayed` (recommended) or `client-signed`. |
| `signerAddress` | Conditional | Required in `client-signed` mode. Omit in `brickken-relayed` mode (Brickken signs). |
| `tokenAddress` | Yes | Agent token contract address. |
| `spenderAddress` | Yes | Wallet approved to spend tokens. |
| `amount` | Yes | Human-readable allowance amount. |
| `decimals` | No | Token decimals used to normalize `amount`. |

## Response

Returns prepared unsigned transactions and `txId`. Submit it to `POST /send-transactions`: in `brickken-relayed` mode send `{ txId, transactions }` and pay via x402 (Brickken signs and broadcasts); in `client-signed` mode sign the transaction locally and send `{ txId, signedTransactions }`.
