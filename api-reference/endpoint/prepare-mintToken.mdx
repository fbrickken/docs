---
title: 'mintToken'
openapi: 'POST /prepare-transactions/mintToken'
---

Prepares unsigned transactions for minting tokens to specified users. This endpoint is equivalent to calling `/prepare-transactions` with `method=mintToken`.

## Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `signerAddress` | string | Yes | Address that will sign the transaction |
| `chainId` | string | Yes | Blockchain network identifier (hex format) |
| `tokenSymbol` | string | Yes | Symbol of the token to mint |
| `userToMint` | array | Yes | Array of users to mint tokens to |
| `gasLimit` | string | No | Optional gas limit |
| `rpcUrl` | string | No | Optional RPC URL |

### userToMint Object Structure

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `email` | string | Yes | Email of the recipient |
| `investorAddress` | string | Yes | Address of the recipient |
| `amount` | string | Yes | Amount of tokens to mint |
| `needWhitelist` | boolean | Yes | Whether the user needs to be whitelisted |

## Example Request

```json
{
  "signerAddress": "0x742d35Cc6634C0532925a3b8D4C9db96c4b4d8b",
  "chainId": "aa36a7",
  "tokenSymbol": "EXMPL",
  "userToMint": [
    {
      "email": "investor@example.com",
      "investorAddress": "0x456...",
      "amount": "100",
      "needWhitelist": true
    }
  ]
}
```

## Response

Returns an array of unsigned transactions that need to be signed and a transaction ID for tracking.

      "value": {"type": "BigNumber", "hex": "0x00"},
      "nonce": 1,
      "chainId": 11155111,
      "data": "0x...",
