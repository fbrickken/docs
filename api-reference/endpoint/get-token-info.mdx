---
title: 'Get Token Information'
openapi: 'GET /get-token-info'
---

Reads token information. This endpoint has two modes, selected by whether you send `tokenSymbol`.

<Note>
This endpoint does **not** return the deployed token contract address. After a `newTokenization` succeeds, read
the address from [`GET /get-tokenizer-info`](/api-reference/endpoint/get-tokenizer-info) as `tokenAddress`.
It also does not return wallet balances — use
[`GET /get-balance-whitelist`](/api-reference/endpoint/get-balance-whitelist) for those.
</Note>

## Query Parameters

- `tokenSymbol` (optional): Token symbol. Omit it to list what the API key can see.

## Mode 1 — list what the API key can see

Omit `tokenSymbol`. Useful right after a tokenization, to confirm the new symbol is registered.

```bash
curl --request GET \
  --url 'https://api.sandbox.brickken.com/get-token-info' \
  --header 'x-api-key: YOUR_API_KEY'
```

```json
{
  "tokenSymbols": [
    "EXMPL"
  ],
  "tokenizerEmails": [
    "tokenizer@example.com"
  ]
}
```

## Mode 2 — read one asset record

Send `tokenSymbol`. Your key must be the tokenizer of that token, or the call returns `Unauthorized token symbol`.

```bash
curl --request GET \
  --url 'https://api.sandbox.brickken.com/get-token-info?tokenSymbol=EXMPL' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Where to find each address

| You need | Endpoint | Field |
| --- | --- | --- |
| Token contract address | [`GET /get-tokenizer-info`](/api-reference/endpoint/get-tokenizer-info) | `tokenAddress` |
| Payment token address | [`GET /get-tokenizer-info`](/api-reference/endpoint/get-tokenizer-info) | `paymentTokenAddress` |
| Escrow address | [`GET /get-tokenizer-info`](/api-reference/endpoint/get-tokenizer-info) | `escrowAddress` |
| Factory and BKN addresses | [`GET /get-network-info`](/api-reference/endpoint/get-network-info) | `factoryAddress`, `BKNAddress` |
| Holder balance | [`GET /get-balance-whitelist`](/api-reference/endpoint/get-balance-whitelist) | `tokenBalance` |
