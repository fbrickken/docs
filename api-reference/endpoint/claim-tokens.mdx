---
title: 'Claim Tokens'
openapi: 'POST /prepare-transactions'
---

This endpoint prepares transactions for claiming tokens from an STO investment.

## Method

Use the `claimTokens` method in your request to prepare token claiming transactions.

```json
{
  "method": "claimTokens",
  "signerAddress": "0x...",
  "chainId": "0x1",
  // Additional claiming parameters
}
```
