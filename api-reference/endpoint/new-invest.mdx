---
title: 'New Investment'
openapi: 'POST /prepare-transactions'
---

This endpoint prepares transactions for making a new investment in an STO.

## Method

Use the `newInvest` method in your request to prepare investment transactions.

```json
{
  "method": "newInvest",
  "signerAddress": "0x...",
  "chainId": "0x1",
  // Additional investment parameters
}
```
