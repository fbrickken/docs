---
title: 'Get Tokenizer Information'
openapi: 'GET /get-tokenizer-info'
---

Retrieves information about the tokenizer for a specific token.

## Query Parameters

- `tokenSymbol` (required): Token symbol

## Example

```bash
curl --request GET \
  --url 'https://api.sandbox.brickken.com/get-tokenizer-info?tokenSymbol=EXMPL' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

```json
{
  "companyWalletAddress": "0x0000000000000000000000000000000000000001",
  "paymentTokenAddress": "0x0000000000000000000000000000000000000001",
  "escrowAddress": "0x0000000000000000000000000000000000000002",
  "chainId": "aa36a7",
  "email": "tokenizer@example.com"
}
```
