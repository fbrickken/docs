---
title: 'Get STO Balance'
openapi: 'GET /get-sto-balance'
---

Retrieves the balance of an STO.

## Query Parameters

- `tokenSymbol` (required): Token symbol
- `id` (required): STO ID

## Example

```bash
curl --request GET \
  --url 'https://api.sandbox.brickken.com/get-sto-balance?tokenSymbol=EXMPL&id=123' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

```json
{
  "balance": "50000"
}
```
