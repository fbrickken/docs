---
title: 'Get STO Balance'
openapi: 'GET /get-sto-balance'
---

Reads one offering together with how much it has raised and how much is still available.

## Query Parameters

- `tokenSymbol` (required): Token symbol
- `id` (required): Offering `uuid`, as returned by [`GET /get-stos`](/api-reference/endpoint/get-stos)

## Example

```bash
curl --request GET \
  --url 'https://api.sandbox.brickken.com/get-sto-balance?tokenSymbol=EXMPL&id=a5232594-3f97-47d0-b362-491caac9388f' \
  --header 'x-api-key: YOUR_API_KEY'
```
