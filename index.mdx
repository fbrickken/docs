## Two APIs

| | Dapp API | Agentic API |
| --- | --- | --- |
| **What it does** | Tokenize assets, run offerings, manage investors and dividends | ERC-8004 agent identity and reputation, agent-owned tokens, ERC-8226 mandates |
| **Credential** | API key | x402 payment, or an API key in `client-signed` mode |
| **Networks** | Ethereum, Base, BNB Chain, Polygon, and their testnets | Base and Base Sepolia; Ethereum Sepolia for RAMS |
| **Who it's for** | Issuers, platforms, and their backends | Autonomous agents and the people who run them |
| **Start here** | [Dapp API](/api-reference/introduction) | [Agentic API](/api-reference/endpoint/agentic-methods-x402) |

Every write on both APIs follows the same three steps: **prepare** an unsigned transaction, **sign** it, **send** it. Preparing is always free.
