Maps to `ramsFreezeAgent`. `signerAddress` must hold `ENFORCER_ROLE` on AgentMandate. It is always client-signed and freezes the agent across all mandates in that registry.

The AgentMandate admin cannot also be its enforcer (`AdminEnforcerOverlap`). Use a distinct operational wallet.
