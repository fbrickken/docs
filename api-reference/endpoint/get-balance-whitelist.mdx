---
title: 'Get Balance and Whitelist Status'
openapi: 'GET /get-balance-whitelist'
---

Retrieves token balance and whitelist status for an address.

## Query Parameters

- `tokenSymbol` (required): Token symbol
- `investorEmail` (required): Email of the investor

## Example

```bash
curl --request GET \
  --url 'https://api.sandbox.brickken.com/get-balance-whitelist?tokenSymbol=EXMPL&investorEmail=investor@example.com' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

```json
{
  "balance": "500000000000000000",
  "isWhitelisted": true
}
```
